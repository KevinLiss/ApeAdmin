# ApeAdmin 打包部署指南

> 纯命令式操作，不依赖打包脚本。适合 Linux 宝塔面板 + Nginx 反代场景。

---

## 一、本地打包（开发机执行）

### 1.1 构建前端

```bash
cd frontend
npm run build
```

产物在 `frontend/dist/`。

### 1.2 打包部署包

在项目根目录执行：

```bash
# 创建临时打包目录
rm -rf /tmp/apeadmin-pkg
mkdir -p /tmp/apeadmin-pkg/frontend_dist

# 拷贝后端源码（不含虚拟环境、缓存、测试）
cp -r backend/src /tmp/apeadmin-pkg/
cp -r backend/alembic /tmp/apeadmin-pkg/
cp backend/alembic.ini /tmp/apeadmin-pkg/
cp backend/pyproject.toml /tmp/apeadmin-pkg/
cp backend/requirements.txt /tmp/apeadmin-pkg/

# 拷贝前端构建产物
cp -r frontend/dist/* /tmp/apeadmin-pkg/frontend_dist/

# 拷贝部署配置（可选参考）
mkdir -p /tmp/apeadmin-pkg/nginx
cp deploy/nginx/apeadmin.conf /tmp/apeadmin-pkg/nginx/ 2>/dev/null || true
cp deploy/.env.example /tmp/apeadmin-pkg/ 2>/dev/null || true

# 打 tar 包
cd /tmp
tar -czf apeadmin-deploy-$(date +%Y%m%d-%H%M).tar.gz apeadmin-pkg/

# 移到工作目录
mv apeadmin-deploy-*.tar.gz "你的工作目录/"
```

**包结构**（解压即用，无多余层级）：
```
apeadmin-pkg/
├── src/              # 后端 Python 源码
├── alembic/          # 数据库迁移
├── alembic.ini
├── pyproject.toml
├── requirements.txt
├── frontend_dist/    # 前端构建产物（Vue3 SPA）
├── nginx/            # Nginx 配置参考（可选）
└── .env.example      # 环境变量参考（可选）
```

### 1.3 关于底座模式 vs 完整模式

- **底座模式**（默认）：不含 apehub_web 业务插件，仅管理后台框架
- **完整模式**：包含 `src/plugins/builtin/apehub_web/` 全部业务代码

打包底座模式时，上面的拷贝命令自然不含 apehub_web（因为它在 src 下但不影响，安装后通过插件管理按需导入即可）。
如需完整模式，确保 `src/plugins/builtin/apehub_web/` 在拷贝范围内即可，无需特殊处理。

## 二、服务器部署

### 2.1 前置条件

- 宝塔面板已安装
- Nginx 已安装且运行中
- MySQL 已安装（或使用 SQLite 免安装）
- 域名已解析到服务器 IP
- 腾讯云安全组放行 80 端口（TCP 0.0.0.0/0）

### 2.2 上传解压

```bash
# 上传到服务器
scp apeadmin-deploy-*.tar.gz root@服务器IP:/www/wwwroot/

# SSH 登录
ssh root@服务器IP

# 解压（注意：解压后是 apeadmin-pkg/，重命名为 apeadmin）
cd /www/wwwroot
tar -xzf apeadmin-deploy-*.tar.gz
mv apeadmin-pkg apeadmin
cd apeadmin
```

### 2.3 创建虚拟环境 + 安装依赖

```bash
# 创建虚拟环境
python3 -m venv .venv

# 激活
source .venv/bin/activate

# 升级 pip
pip install --upgrade pip

# 安装依赖（阿里云镜像加速）
pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/

# 确认 uvicorn 可用
which uvicorn
# 应输出: /www/wwwroot/apeadmin/.venv/bin/uvicorn
```

### 2.4 注册 systemd 服务

```bash
cat > /etc/systemd/system/apeadmin.service << 'EOF'
[Unit]
Description=ApeAdmin Backend (FastAPI)
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/www/wwwroot/apeadmin
ExecStart=/www/wwwroot/apeadmin/.venv/bin/uvicorn src.main:app --host 127.0.0.1 --port 8000 --workers 1 --proxy-headers --forwarded-allow-ips 127.0.0.1
Restart=always
RestartSec=5
Environment=PYTHONUNBUFFERED=1
StandardOutput=append:/var/log/apeadmin/app.log
StandardError=append:/var/log/apeadmin/app.log

[Install]
WantedBy=multi-user.target
EOF

# 创建日志目录
mkdir -p /var/log/apeadmin

# 重载 systemd 并启动
systemctl daemon-reload
systemctl enable apeadmin
systemctl start apeadmin

# 验证
systemctl status apeadmin
curl http://127.0.0.1:8000/health
# 应返回: {"code":200,"msg":"success","data":{"app":"ApeAdmin","version":"0.1.0","status":"setup"}}
```

> **注意 status 为 "setup"**：正常，说明进入安装向导模式。

### 2.5 配置 Nginx 反代

```bash
cat > /www/server/panel/vhost/nginx/apehub.finecv.cn.conf << 'EOF'
server {
    listen 80;
    server_name apehub.finecv.cn;

    client_max_body_size 100m;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_buffering off;
        proxy_read_timeout 3600s;
    }
}
EOF

# 重载 Nginx
nginx -t && nginx -s reload
```

> 把 `apehub.finecv.cn` 换成你的实际域名。

### 2.6 禁用宝塔自动生成的冲突配置

如果通过宝塔面板添加过 Python 项目，宝塔会自动生成一份 Nginx 配置，和我们的冲突：

```bash
# 查看是否有冲突配置
ls /www/server/panel/vhost/nginx/python_apeadmin.conf 2>/dev/null

# 如果存在，禁用它
mv /www/server/panel/vhost/nginx/python_apeadmin.conf /www/server/panel/vhost/nginx/python_apeadmin.conf.disabled
nginx -t && nginx -s reload
```

### 2.7 配置日志轮转

```bash
cat > /etc/logrotate.d/apeadmin << 'EOF'
/var/log/apeadmin/*.log {
    daily
    rotate 30
    compress
    delaycompress
    notifempty
    missingok
    copytruncate
    dateext
}
EOF
```

### 2.8 宝塔面板配置日志路径

1. 宝塔面板 → 网站 → Python 项目 → apeadmin → 设置
2. 左侧选「项目日志」
3. 日志路径填：`/var/log/apeadmin`
4. 点保存

## 三、安装向导（浏览器操作）

### 3.1 访问安装向导

浏览器打开 `http://你的域名/`，自动跳转到 `/setup`。

### 3.2 三步安装

**第 1 步：数据库配置**
- 选 MySQL 或 SQLite
- MySQL：填数据库地址、端口、用户名、密码、数据库名
  - 宝塔面板 → 数据库 可查看连接信息
  - 数据库不存在会自动创建（需账号有建库权限）
- 点「测试连接」验证

**第 2 步：站点与管理员配置**
- 站点名称
- 站点访问地址（如 `http://apehub.finecv.cn`）
- 管理后台路径（默认 `/admin`）
- 管理员账号 + 密码

**第 3 步：安装**
- 点「开始安装」
- 等待建表完成
- 页面显示安装成功信息（**保存管理员密码！只显示一次**）

### 3.3 重启服务

安装完成后，在服务器上执行：

```bash
systemctl restart apeadmin
```

重启后安装向导页面会自动检测到服务已重启，按钮变为「进入站点」。

### 3.4 验证

```bash
# 健康检查应为 healthy
curl http://127.0.0.1:8000/health

# /setup/api/status 应返回 404（说明已退出 setup 模式）
curl -o /dev/null -w "%{http_code}" http://127.0.0.1:8000/setup/api/status

# /admin/ 应返回 200
curl -o /dev/null -w "%{http_code}" http://127.0.0.1:8000/admin/
```

浏览器访问 `http://你的域名/admin/`，用安装时设的账号密码登录。

## 五、常见问题

### Q: 宝塔 Python 项目启动失败 `No module named uvicorn`
A: 宝塔用系统 Python 启动，不认项目虚拟环境。不用宝塔管进程，用 systemd。

### Q: Nginx 502
A: 检查是否有宝塔自动生成的 `python_apeadmin.conf` 冲突配置，禁用它。

### Q: 外网访问不了
A: 检查腾讯云安全组是否放行 80 端口。

### Q: /admin/login 返回 404
A: 确认 `main.py` 使用的是 `SpaStaticFiles` 子类（有 fallback 到 index.html 的逻辑）。

### Q: 登录后跳转到 /login 而不是 /admin/login
A: 检查 `frontend/src/api/request.ts` 中 401 拦截器是否用 `/admin/login`。

### Q: 验证码不显示
A: 确认验证码插件已启用（后台 → 插件管理 → 启动验证码插件）。如未安装验证码插件，登录页不展示验证码输入框，不影响正常登录。

### Q: 安装向导页面打开是空白
A: 检查 `/var/log/apeadmin/app.log` 是否有报错，确认 Python 依赖已完整安装。

### Q: 服务能启动但数据库连不上
A: 检查 `.env` 中数据库配置是否正确，确认 MySQL 用户有权限访问对应数据库。

## 七、关键注意事项

1. **必须单 worker**：`--workers 1`，插件热拔插运行态是进程本地的
2. **必须 --proxy-headers**：反代场景下还原真实客户端 IP
3. **安装只建表不 seed**：seed 延迟到重启后（JWT_SECRET 密钥轮换问题）
4. **不要用宝塔管进程**：用 systemd 直接管，宝塔只看日志
5. **安全组放 80**：腾讯云控制台 → 防火墙 → TCP:80 允许 0.0.0.0/0
6. **部署包扁平结构**：解压即 `apeadmin-pkg/`，不要嵌套 backend/ 目录
