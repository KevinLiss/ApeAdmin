技术文档

插件的安装配置、接口说明与使用指南。

安装方式

方式一：ZIP 上传安装
# 1. 在管理后台 → 系统管理 → 插件管理
# 2. 点击「上传安装」，选择 ai-chat-engine-v2.1.0.zip
# 3. 系统自动解压、发现、注册插件
# 4. 安装后可在 AI 助手菜单使用
方式二：手动安装
cd backend/src/plugins/builtin/
# 将插件包放入 builtin 目录
# 重启后端，插件自动发现并加载
uvicorn src.main:app --reload

配置说明

.env 配置项
# AI 对话引擎配置
AI_DEFAULT_PROVIDER=deepseek
AI_DEFAULT_MODEL=deepseek-chat
AI_MAX_TOOL_ROUNDS=5
AI_STREAM_ENABLED=true

# 供应商密钥（在后台 AI 助手 → 密钥管理中添加）
# DeepSeek → https://api.deepseek.com
# 通义千问 → https://dashscope.aliyuncs.com/compatible-mode/v1

MCP 工具注册

plugin.py
def register_mcp_tools(self, mcp_manager):
    @mcp_manager.tool("ai_chat_send", "发送AI对话消息")
    def send_message(message: str, model: str = "deepseek-chat") -> dict:
        """向AI模型发送消息并获取响应"""
        return agent.chat(message, model)
