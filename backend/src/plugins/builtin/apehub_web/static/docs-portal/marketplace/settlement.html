USDT 支付与结算 ​

购买 ​

插件以 USDT 计价，通过 LemPay usdt 通道创建订单。平台会验证回调签名、商户 ID、支付类型、订单金额、商品名称和 TRADE_SUCCESS 状态。支付成功后建立插件永久权益。

退款期限 ​

退款期限由后台配置。退款时会撤销下载权益；如果开发者收益已经可用，平台需要执行对应的冲正策略，因此结算周期应至少覆盖退款风险窗口。

开发者收益 ​

订单会记录原始金额、平台服务费比例、平台服务费和开发者收益。支付成功后收益先进入待结算，达到“结算周期”和“退款期限”两者中的较大值后才可提现。

提现 ​

  • 计价币种：USDT
  • 网络：USDT-TRC20
  • 最低金额：后台可配置，默认 100 USDT
  • 手续费：后台可配置固定金额或百分比
  • 打款：管理员人工打款
  • 完成条件：管理员确认时必须填写 TRC20 交易哈希

提现状态为“待审核 → 已通过待打款 → 已完成”，驳回时释放冻结余额。
