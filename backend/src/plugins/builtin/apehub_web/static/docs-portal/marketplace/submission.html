提交与 AI 分析 ​

提交资料 ​

开发者在官网 个人中心 创建插件草稿，填写插件标识、展示名称、介绍、分类、标签、USDT 定价、Logo、轮播图和 Demo 信息。创建插件只产生草稿，不会立即出现在市场。

版本工作台 ​

每个插件可以维护多个版本。上传 ZIP 时，平台会校验包结构、文件大小、plugin.json 和版本号；同一版本只保留一个当前安装包。文档、更新说明和兼容性信息都属于版本，而不是全局插件资料。

AI 技术文档 ​

上传包后先执行静态检查，再由 DeepSeek 根据文件树和源码摘要生成 Markdown。生成结果只写入当前版本草稿，开发者可以人工修改后再提交审核。

AI 分析不是自动放行机制：管理员仍需查看风险提示、源码文件、权限需求和版本文档。

WARNING

不要在插件包中提交 API Key、密码、令牌、私钥、生产数据库连接串或用户隐私数据。

提交流程 ​

text
创建插件 → 创建版本 → 上传安装包 → 静态检查
                              ↓
                    AI 生成文档（可重试）
                              ↓
                    人工完善 → 提交审核

审核通过后还需要管理员单独执行“发布上架”，发布动作才会让版本进入公开市场。
