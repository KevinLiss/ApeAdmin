MCP Gateway

把管理系统变成 AI 的工具

通过 MCP-SSE 网关，将底座与插件的管理能力封装为标准化 AI 工具，实现传统业务系统与大模型智能体的无缝打通。

一条 @mcp_manager.tool
让 Agent 直接接管系统

插件只需几行代码即可向 MCP 网关注册工具。AI Agent 调用时自动进行 RBAC 过滤与审计，权限安全无缝延续。

✓
三原语支持Tools 工具调用 / Resources 资源读取 / Prompts 模板渲染
✓
自动 Schema从函数签名自动推断 JSON Schema，无需手写
✓
RBAC 过滤Agent 只能看到当前用户有权限调用的工具
✓
全程审计每次工具调用自动记录请求、响应、耗时与调用者
plugin.py · 向 MCP 注册工具 
@mcp_manager.tool("my_plugin_greet", "问候工具")
def greet(name: str) -> dict:
    """向指定用户问候"""
    return {"message": f"Hello, {name}!"}

# AI Agent 侧即可调用：
tools = mcp.build_tools(user)
result = await agent.call("问候小张")
# → {"message": "Hello, 小张!"}

Quick Start

三分钟跑起来

默认使用 SQLite 零配置启动，无需额外安装数据库。

1
启动后端

Python 3.11+，创建虚拟环境后安装依赖，一行命令跑起 FastAPI。

2
启动前端

Node.js 18+，npm install 后 npm run dev，访问 localhost:5173。

3
登录体验

使用默认账号 admin / admin123 登录，开始管理你的系统。

terminal 
# 后端
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -e .
uvicorn src.main:app --reload --port 8000

# 前端
cd frontend
npm install --legacy-peer-deps
npm run dev   # http://localhost:5173

# 默认账号：admin / admin123
