# 版本与审核

```text
草稿 → AI 分析 → 提交 → 审核中 → 审核通过 → 发布
  ↑       ↓                    ↓
  └── 分析失败/驳回 ←───────────┘
```

## 审核与发布分离

管理员审核时可以查看版本文件树、源码预览、静态风险提示、开发者资料和历史审核记录。首次通过时设置平台服务费百分比。审核通过不会自动上架，必须再次执行“发布上架”。

发布新版本后，旧版本保留在版本树中并标记为历史版本；市场默认展示当前发布版本，已购买用户可以继续下载所有已发布版本。

## 版本修改边界

草稿、分析失败和驳回版本可以修改。审核中、已通过和已发布版本不能直接覆盖；需要创建新的版本提交，保证已审核内容和已售内容可追溯。

## 版本权益

用户购买一次后对该插件建立永久权益，可下载当前与以后的全部已发布版本。退款完成后权益撤销，后续下载会被拒绝。
